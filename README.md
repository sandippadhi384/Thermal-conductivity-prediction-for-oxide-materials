# Machine Learning for Thermal Transport in Oxide Materials

This repository contains the data-curation, feature-generation, machine-learning,
stacking, evaluation, and feature-analysis workflows used in our study of thermal
transport in SrSnO₃.

The workflow includes composition-based feature generation using Matminer,
artificial neural network (ANN) and gradient boosting (GB) models, SVR-based
stacking, model evaluation, and feature-importance analysis.

This code is provided to facilitate reproducibility and further research based on
our published work.
